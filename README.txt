# Idly Katha website

This is a responsive HTML/CSS/JS recreation of the supplied Idly Katha landing-page mockup.

## Folder structure

idly-katha-website/
  index.html
  styles.css
  script.js
  images/

## Images to upload

Put these files inside `images/` with these exact names:

1. `logo.png` — Idly Katha circular logo.
2. `hero.jpg` — main restaurant/entrance hero background.
3. `place-counter.jpg` — tiffin counter image.
4. `place-decor.jpg` — traditional wall/decor image.
5. `place-seating.jpg` — seating area image.
6. `place-entrance.jpg` — entrance image.
7. `gallery-entrance.jpg` — gallery entrance photo.
8. `gallery-counter.jpg` — gallery counter photo.
9. `gallery-seating.jpg` — gallery seating photo.
10. `gallery-village.jpg` — village artwork/wall painting.
11. `gallery-decor.jpg` — traditional decor photo.
12. `food-idly.png` — transparent/background-clean idly food photo.
13. `food-dosa.png` — transparent/background-clean dosa photo.
14. `food-vada.png` — transparent/background-clean vada photo.
15. `food-poori.png` — transparent/background-clean poori photo.
16. `footer-village.png` — village/palm-tree footer illustration.

## Recommended image sizes

- `hero.jpg`: 1920×900 or larger, landscape.
- Place/gallery images: 1200×800 or larger.
- Food PNGs: 800×800 or larger, preferably transparent PNG.
- `logo.png`: 1000×1000 PNG with transparent background.
- `footer-village.png`: 1920×300 or larger, landscape PNG/JPG.

## How to run

Upload the complete folder to your hosting/GitHub repository. Open `index.html`.

For GitHub Pages, keep `index.html` in the published root and make sure the `images` folder is uploaded exactly as shown.

## Important

The text, prices, address, phone number and timings in this template follow the supplied mockup. Replace them in `index.html` if your real business details are different.
